# Video MP4 v6 — iPhoneアプリ風版

App Store公開なしで、iPhoneのホーム画面からアプリのように起動するPWAです。

## できること
- Wikimedia Commonsの動画検索
- 各動画の詳細・ライセンス確認
- MP4動画の保存
- 対応可能な動画形式をH.264/AACのMP4へ変換
- iPhone内の動画をMP4へ変換
- 保存履歴
- ホーム画面用アイコン

## iPhoneでの利用
1. HTTPSで公開したサイトをSafariで開く
2. 共有ボタン
3. 「ホーム画面に追加」
4. 「Video MP4」を起動

※このZIPだけではHTTPS公開済みのサイトにはなりません。
※DRM解除、アクセス制限回避、提供元が禁止するダウンロードは行いません。
※各動画のライセンス条件を確認し、その条件に従って利用してください。
